# Mestrado

Em Modelos, estão as arquiteturas implementadas. Modelo I com \textit{self-attention}; Modelo II com \textit{Bahdanau attention}; Modelo III com um \textit{Transformer Encoder}. De maneira que, além da marcação dos picos R, foi possível a extração do FECG. Por fim, o Modelo IV baseado no III, porém com o uso de um mecanismo de refinamento (\textit{encoder-decoder}) recebendo a saída anterior concatenada à entrada original. O Modelo IV contém duas versões: uma prevê o FECG (a) e a outra não (b). Para a integração do projeto original, o Modelo IV-b foi descrito em C, sendo realizada a análise de \textit{profiling}, em um Intel(R) Xeon(R) Platinum 8259CL, para verificar as camadas mais exigentes computacionalmente, resultando no tempo de execução em \textit{Python} igual a 108,47 ms, comparado com 73,94 ms em C. Como esperado, o \textit{Transformer} e as \textit{LSTMs} foram os mais complexos em número de parâmetros.

O Modelo IV-b se sobressaiu tanto em comparação com os modelos deste estudo como com os do estado da arte, sendo capaz de lidar de forma confiável com dados reais. Futuramente, deve-se integrar o modelo em C em um SoC (\textit{System on a Chip}) para o andamento do protótipo de monitoramento.
